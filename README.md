# Sensor Academy

A modern learning platform focused on technology education, software development, AI innovation, and practical digital skills.

---

## Overview

Sensor Academy is an educational platform designed to help students, beginners, and tech enthusiasts learn modern digital skills through structured courses, projects, mentorship, and real-world practice.

The platform provides interactive learning experiences in areas such as:

* Full Stack Web Development
* Artificial Intelligence
* Frontend Development
* Backend Development
* Mobile App Development
* UI/UX Design
* Database Management
* API Development
* Tech Career Guidance

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/sensor-academy.git
```

Open the project folder:

```bash
cd sensor-academy
```

Install dependencies:

```bash
npm install
```

---

## Environment Variables

Create a `.env` file in the root directory:

```env
DATABASE_URL=your_database_url
PORT=3000
JWT_SECRET=your_secret_key
```

---

## Prisma Setup

Generate Prisma client:

```bash
npx prisma generate
```

Push database schema:

```bash
npx prisma db push
```

---

## Running the Project

Start development server:

```bash
npm run dev
```

Frontend:

```txt
http://localhost:3000
```
